# Trip Service (Лабораторная работа 1)

Сервис управления поездками (Trip Service), реализованный на Go (HTTP API + PostgreSQL).
Сервис спроектирован по подходу API-first на основе контракта OpenAPI, использует `pgxpool` для работы с БД, SQL-билдер `squirrel` и контекстный менеджер транзакций.

---

### Защита от гонок при завершении поездки
**Проблема:** При одновременных запросах на завершение поездки раздельные шаги проверки статуса и записи создают окно уязвимости, из-за чего оба запроса могут завершиться с кодом 200 и перезаписать `finished_at`.

**Решение:** Проблема решена методом атомарного условного обновления:
```sql
UPDATE trips
SET status = 'completed', finished_at = $1
WHERE id = $2 AND status = 'active'
RETURNING ...;
